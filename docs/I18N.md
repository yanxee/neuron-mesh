# Documentation Languages

[English](I18N.md) | [简体中文](I18N.zh-CN.md)

NeuronMesh publishes public project documentation in English and Simplified Chinese.

## File convention

- `name.md`: English document;
- `name.zh-CN.md`: Simplified Chinese companion;
- Chinese research reports remain at their original paths;
- the English technical edition is placed under `docs/research/*.en.md`.

Every paired document starts with a language switch. A change to security, architecture, API, test commands or claims must update both files in the same pull request.

## Scope

The bilingual policy covers:

- README, architecture, roadmap, security, governance, changelog and contributor policies;
- contributor guides, demos, task boards and outreach material;
- architecture contracts, threat model and quality scenarios;
- research plans and technical disclosure;
- public website pages, navigation and search descriptions;
- GitHub Issue forms, pull-request template and repository description.

Code identifiers, protocol names, external standards and machine-readable keys remain in English.

## Authority

For software behavior, the tested implementation and machine-readable contract are authoritative. For the technical disclosure and patent-oriented wording, the Chinese source remains legally authoritative. These rules do not make untranslated guesses valid.

## Review

A translation is complete when:

1. the paired file exists and is linked;
2. headings and critical warnings are semantically equivalent;
3. commands, paths, version numbers and external links remain correct;
4. unsupported capabilities are not strengthened or weakened;
5. relative links resolve in CI.

Translations are credited as project contributions.
