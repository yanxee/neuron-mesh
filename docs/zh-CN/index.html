让异构主机组成可验证、带持久记忆的大模型网络。

NeuronMesh 将电脑、服务器和边缘设备连接为按能力调度的 AI 网格。请求可从任意授权节点进入， 虚拟角色可以跨主机携带加密记忆，断网节点可退回本地自治推理。

查看中文项目说明 运行双节点演示 参与贡献

这是研究原型，不宣称已经实现生产级公网 LLM 集群或物理上永久存在的记忆。

研究方向

不止是另一个集中式聊天 API

入口侧规划

任意受邀节点可以作为入口，模型执行是可解释、可审计的显式决策。

异构算力

强弱神经元由持续吞吐、内存、热限制和网络路径质量推导，而不是设备名称。

持久记忆

AES-GCM 内容、盲词法索引、热/温/冷分层和跨故障域加密副本。

可迁移虚拟角色

角色身份、命名空间和 Adapter 从物理主机解耦，可通过一次性密钥迁移。

离线自治

在线和离线模式明确展示能力边界，而不是静默失败。

优雅降级

排空、容量租约、副本确认和签名关机回执让生命周期操作可度量。

架构

联邦式设计，显式表达失败。

成员、发现与规划、执行、持久状态、学习和审计是分离平面。任意节点都可以成为入口，但没有全局调度器拥有所有请求。

v0.2.0 是参考切片。完整目标契约、状态所有者和实现差距均公开。
