首次贡献

短反馈环，清晰证据。

  1. 选择。 挑选 Issue，或在 Discussion 中提出具体提案。
  2. 认领。 说明计划展示的结果和失败边界。
  3. 构建。 保持补丁聚焦，并附测试、基准或复现命令。
  4. 评审。 准备回答正确性、安全和隐藏假设问题。
  5. 署名。 发布成果按贡献类型署名，除非你选择匿名。

值得负责的问题。

传输

评估 libp2p QUIC、AutoNAT/DCUtR、中继回退、NAT 矩阵和分区恢复。

推理

为 llama.cpp、vLLM 和确定性测试 Worker 定义后端与阶段清单契约。

记忆

测量 Recall@K、上下文 token 成本、加密恢复延迟和投毒防御。

信任

用命名空间授权替换邀请网共享 token，并评审密钥恢复。

持续学习

设计隔离安全的联邦 LoRA 实验，包含回归门槛和遗忘审计。

空间接口

定义与平台无关的 WebXR/OpenXR 适配器，避免记忆绑定单一引擎。
