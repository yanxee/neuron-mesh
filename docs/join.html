First contribution

A short loop with visible evidence.

  1. Choose. Pick an issue or post a concrete proposal in Discussions.
  2. Claim. State the result and failure boundary you intend to demonstrate.
  3. Build. Keep the patch focused and include a test, benchmark or reproduction command.
  4. Review. Expect questions about correctness, security and hidden assumptions.
  5. Credit. Released outcomes are credited by contribution type unless you opt out.
