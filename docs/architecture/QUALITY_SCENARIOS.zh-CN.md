# 架构质量场景

[English](QUALITY_SCENARIOS.md) | [简体中文](QUALITY_SCENARIOS.zh-CN.md)

**状态：** 验收场景基线 `v0.1`

这些场景定义架构的可观测结果。标记为“目标”的场景尚未实现。

## 1. 容量选择

### QS-01：高规格节点处于热压力

**给定** GPU 节点已为模型阶段公布完成基准，  
**且** 当前温度或电源策略不再允许承诺的持续速率，  
**当** 入口请求容量，  
**则** 节点提供缩减容量或拒绝该阶段，  
**且** 规划器不得将其选入延迟关键租约，  
**且** 旧的 strong 分类不能当作当前可用性证明。

证据：能力 epoch、基准 ID、当前租约拒绝原因和规划器决定。

### QS-02：两个模型层数相同但 Tokenizer 不同

**给定** 两个阶段清单覆盖连续层，  
**且** Tokenizer 或聊天模板摘要不同，  
**当** 入口构造管线，  
**则** 规划在任何 Worker 启动前以 `manifest_incompatible` 失败，  
**且** 不发送激活或 token。

**当前状态：** 目标。当前只路由完整模型，不执行管线阶段。

## 2. 请求执行

### QS-03：Worker 在首次输出前失败

**给定** 已准入流式请求仍有截止时间和预算，  
**且** 尚未发出用户可见 token，  
**当** 某阶段失败，  
**则** 入口可在同一幂等键内重新规划，  
**且** 释放未使用租约，  
**且** 终态回执记录两次尝试。

### QS-04：Worker 在首次输出后失败

**给定** 客户端已收到至少一个生成 token，  
**当** Worker 或网络失败，  
**则** 除非支持 checkpoint 协议，流以可恢复失败结束，  
**且** 入口不静默重放请求，  
**且** 不产生重复副作用。

**当前状态：** 远端流式故障行为尚未完整测试。

### QS-05：重复请求投递

**给定** 客户端使用相同幂等键和完全相同的规范化输入重试已完成请求，  
**当** 入口收到重复请求，  
**则** 返回既有终态或附着到现有活跃请求，  
**且** 不执行两次 Worker。

**当前状态：** 目标。API 幂等键尚未实现。

## 3. 成员与租约

### QS-06：请求期间节点被撤销

**给定** Worker 在成员 epoch `N` 持有活跃租约，  
**当** 成员 epoch `N+1` 撤销该节点，  
**则** 撤销边界后不再接受 epoch `N` 的新租约或提交，  
**且** 请求进入明确的安全重试或终态，  
**且** 证据保留两个 epoch。

### QS-07：Worker 暂停期间租约过期

**给定** 被暂停 Worker 持有 fence `F`，  
**当** 租约过期且另一 Worker 获得 `F+1`，  
**则** 旧 Worker 不能提交，  
**且** 其迟到结果被拒绝或隔离，  
**且** 只有被接受工作进入核算。

**当前状态：** 目标。

## 4. 持久记忆

### QS-08：所需远端副本未确认

**给定** 记忆写入请求 D2，  
**且** 唯一远端存储尝试失败，  
**当** 本地提交成功，  
**则** 响应显示 `degraded`/D1 而不是 D2，  
**且** 副本清单不记录虚假确认，  
**且** 修复队列安排另一兼容托管节点。

### QS-09：D2 确认后源主机本地盘全部损坏

**给定** 一个 D2 记忆具有一个已确认远端密文副本且恢复密钥可访问，  
**当** 源主机磁盘被摧毁，  
**则** 授权恢复流程找到已验证远端清单，  
**且** 恢复准确提交版本，  
**且** 报告实测 RPO/RTO 和密钥托管假设。

**当前状态：** 已有远端密文存储；自动密钥恢复和实测灾难恢复演练尚未实现。

### QS-10：已删除记忆仍存在于陈旧副本

**给定** 对象版本 `V3` 已提交删除 epoch `E7`，  
**且** 离线托管节点稍后返回 `V3`，  
**当** 反熵比较副本和墓碑 epoch，  
**则** 陈旧对象被删除或不可访问，  
**且** 不再可检索，  
**且** 删除债务保持可见，直到所有已知副本解决。

**当前状态：** 仅尽力传播，无墓碑反熵。

### QS-11：命名空间密钥不可用

**给定** D2/D3 加密记忆存在，  
**且** 当前设备密钥不可用，  
**当** 所有者尝试恢复，  
**则** 系统要求授权恢复许可，  
**且** 不替换其他命名空间密钥或错误报告已恢复，  
**且** 结果可审计。

**当前状态：** 实现中没有命名空间密钥恢复架构。

## 5. 虚拟角色

### QS-12：迁移后旧主节点恢复

**给定** 角色从主节点 epoch `E10` 迁移到目标 `E11`，  
**当** 旧主节点以陈旧 `E10` 恢复，  
**则** 不能接受新角色动作或记忆写，  
**且** 其输出不作为活跃状态，  
**且** 运维者可以检查 epoch 不匹配。

### QS-13：目标准备后迁移失败

**给定** 角色已准备目标但尚未推进主节点 epoch，  
**当** 目标验证失败，  
**则** 原主节点保持权威，  
**且** 部分准备目标被删除或隔离，  
**且** 不发生用户可见脑裂。

**当前状态：** 目标；已有导出/导入，但没有自动两阶段迁移和回滚。

## 6. 分区与离线行为

### QS-14：入口与域目录失去联系

**给定** 入口没有当前目录快照，  
**且** 直接 Peer 探测或其他目录副本可用，  
**当** 规划请求，  
**则** 可使用已验证替代发现，  
**且** 不把陈旧目录容量当有效租约，  
**且** 记录发现降级。

### QS-15：节点离线一段时间后重连

**给定** 离线节点有本地记忆/日志变更，  
**当** 重连，  
**则** 在接受远端工作前获取当前成员和策略 epoch，  
**且** 在宣称耐久性前协调墓碑和版本，  
**且** 不重复已提交请求或写入。

## 7. 安全与滥用

### QS-16：恶意 Peer 公布内部 URL

**给定** Peer 公告包含回环、链路本地、元数据服务或禁止重定向目标，  
**当** 节点尝试连接，  
**则** 出站策略在发送凭证前拒绝，  
**且** 生成可审计安全事件，  
**且** 其他 Peer 仍可使用。

**当前状态：** 未实现；当前 HTTP Mesh 在签名校验后信任公布 URL。

### QS-17：存储托管节点被攻破

**给定** 托管节点保存加密记忆块，  
**当** 攻击者获得本地数据库，  
**则** 没有所有者密钥授权无法解密命名空间明文，  
**且** 篡改块通过摘要/认证检查失败，  
**且** 命名空间权威将受影响副本标为 degraded。

### QS-18：投毒记忆尝试持久 Prompt 注入

**给定** 不可信内容包含改变持久策略的指令，  
**当** 进入记忆提取管线，  
**则** 保持不可信证据标签，  
**且** 不能授予权限或覆盖所有者策略，  
**且** 晋升需要显式证据门。

**当前状态：** 目标；当前 API 只保存提交文本，没有提取/巩固管线。

## 8. 持续学习

### QS-19：本地更新降低训练损失但导致安全回归

**给定** 候选 Adapter 降低本地训练目标，  
**当** 全局兼容、回归或安全套件失败，  
**则** 更新被隔离，  
**且** 不进行 canary 或生产发布，  
**且** 评估产物保留用于调查。

### QS-20：一个参与者提交畸形或后门更新

**给定** 多参与者训练轮次，  
**当** 更新来源无效、参数异常或未通过行为探针，  
**则** 聚合器按签名轮次策略排除或隔离，  
**且** 记录决定，同时不宣称密码学上证明诚实。

**当前状态：** 仅设计。

## 9. 空间动作

### QS-21：高影响 Avatar 动作没有当前授权

**给定** 角色允许 speak 和 gesture，  
**当** 模型提出在没有有效短期动作授权时改变共享世界状态，  
**则** 适配器拒绝意图，  
**且** 记录策略原因而不保存原始传感器数据，  
**且** 不把角色整体标记为不安全。

**当前状态：** 已有 prefix-token mock 权限，尚无签名短期授权。

## 10. 发布证据

声称满足某质量场景的 PR 或 Release 必须链接：

- 一致性测试或基准；
- 精确拓扑和版本；
- 故障注入方法；
- 通过/失败标准；
- 残余失败边界；
- 可复现产物。

架构验收不代表生产就绪，只表示下一步验证明确。
