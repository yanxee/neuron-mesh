# 文档语言规则

[English](I18N.md) | [简体中文](I18N.zh-CN.md)

NeuronMesh 的公开项目文档使用英文和简体中文。

## 文件约定

- `name.md`：英文文档；
- `name.zh-CN.md`：简体中文镜像；
- 中文研究报告保留原路径；
- 对应的英文技术版放在 `docs/research/*.en.md`。

所有成对文档顶部都有语言切换链接。涉及安全、架构、API、测试命令或技术主张的变更，必须在同一 Pull Request 中同时更新两种语言。

## 覆盖范围

双语规则覆盖：

- README、架构、路线图、安全、治理、变更日志和贡献政策；
- 贡献指南、演示、任务板和招募材料；
- 架构契约、威胁模型和质量场景；
- 研究方案和技术交底书；
- 公开网站页面、导航和搜索说明；
- GitHub Issue 表单、Pull Request 模板和仓库描述。

代码标识符、协议名称、外部标准和机器可读字段保持英文。

`LICENSE` 英文原文继续作为具有法律约束力的文本。`LICENSE.zh-CN.md` 是非官方参考译文，不能替代原文。

## 权威性

对于软件行为，已测试实现和机器可读契约具有权威性。对于技术交底书和专利措辞，中文原件保持法律意义上的权威性。这些规则不允许用未经翻译确认的猜测替代原文。

## 评审

一个翻译版本完成需满足：

1. 成对文件存在并相互链接；
2. 标题和关键警告语义等价；
3. 命令、路径、版本号和外部链接正确；
4. 未夸大或削弱未实现能力；
5. 相对链接通过 CI。

翻译作为项目贡献获得署名。
